## 〇、统一决策核目标架构

```
每帧：
  perceive(life)  ──►  刺激快照（所有 when 词的布尔 + 目标实体）
       │
  if (reactionDelay 锁存中)  ──►  按 Q5 处理延迟，到点执行锁存动作
       │
  否则 遍历 life.behavior.rules（有序，从上到下第一条命中）
       │  rule.when 在快照为真  ──►  执行 rule.do（带目标）
       │
  全不命中  ──►  默认游荡（seek 加权选目标，或随机游荡）
```

- 写死常量全部提升为 `body` 参数插槽：`senseRadius / personalSpace / speedMul / dwellSec / temperSec / reactionDelaySec`。
- `temperSec`（§12.1 已裁）：被 `hitBy` 激怒后 N 秒内，`strangerNear` 自动套用激怒它的那条规则的 `do`。
- 全局 `reactUntil` 节流保留（防抖），但不再承担"慢性子"语义（那是 `reactionDelaySec`，见 Q5）。

## 一、刺激快照（perceive 重写目标）

每帧为 `life` 计算以下 `when` 词的真值 + 目标实体 `bestTarget`：

| when 词 | 快照判定（草案） |
|---|---|
| `dangerNear` | 自身 `sense` 内出现 `bad_luck` 或浪潮威胁 |
| `hitBy` | 本帧被撞/受击（碰撞事件触发，非每帧轮询） |
| `strangerNear` | `sense` 内有生命，但**无 relationship 记录** |
| `friendHurt` | 存在 relationship 伙伴且 `energy < HURT_E`(=30) |
| `friendThreatened` | relationship 伙伴（`sense` 内）周边有 danger（见 Q1） |
| `newThingNear` | `sense` 内有未观察过的 event / creation / 新资源 |
| `crowded` | `personalSpace` 半径内生命数 ≥ `CROWDED_N`(=3)（见 Q6） |

> 注：资源不进 `when` 词表（06 §5 v1 边界）；贪吃靠 `seek.resources` 表达。

## 二、开口问题拷打（§12.2 应答）

### Q1 · friendThreatened 要不要扫伙伴周边？半径多大？
- **现役**：`perceive`(L795) 只扫自身周边 events/waves，**从不扫伙伴**；三函数里无任何 `friendThreatened` 基础。
- **裁定**：**要扫，但只扫自身 `sense` 内的伙伴**。perceive 新增"伙伴感知"：对每个 relationship 伙伴 `p`（且 `p` 在自身 `sense` 内），检查 `p` 周边 `sense*0.8` 内是否有 danger（`bad_luck` / 浪潮威胁）。命中 → `friendThreatened=true`，目标 = 该 danger 源（供 `confront` 逼近）。远处伙伴顾不上 = 自然（"精但不神"）。
- **已裁定（2026-08-26 用户拍板，选 A）**。

### Q2 · friendHurt「朋友」定义
- **现役**：`relationships` 在 `lifeAI`(L1369, `bd<40` 相遇) 与 social 的 `decidePersonality`(L780) 建立，二元有无；**无"受伤/能量低"传播机制**——生命被打扣 energy，其他生命无从知晓。
- **裁定**：`friend` = 有 relationship 记录者；`hurt` = `energy < HURT_E`(=30, 0–100 标度)。`strangerNear` 用"无关系记录"口径（**不用阈值**）。
- **已裁定（2026-08-26 用户拍板，选 A）**：`friend`=有 relationship 记录；`strangerNear`=附近有生命但无记录（纯二元，否掉 B 的关系阈值口径）；`hurt`=伙伴 `energy<30`。零新增系统。

### Q3 · help 带位移的目标选取
- **现役**：无 `help` 动作（仅相遇 `meet` 原语），更无"跑过去帮"。
- **裁定**：`help` do = 朝目标 friend 提速移动（`speedMul` 加成），到达（`bd < HELP_RANGE`=40）后输能 `+HELP_GAIN`(=15) + `playSkillPrimitive('help')`。**多 hurt 朋友**：选评分最高者 `score = (100-energy) - dist*k`（最近且能量最低优先）。规则顺序（非此处）决定 `friendHurt→help` 是否优先于其他（如 §10#1 排在 `strangerNear→retreat` 前）。
- **待确认**：`HELP_GAIN` 是否受 `caution` 打折（06 §2.3 吃资源收益打折）？

### Q4 · observe 驻留计时器放哪
- **现役**：`state='observing'` 是瞬时态（L823/L1367），无驻留时长锁；`lifeAI` 每帧把最近实体当观察对象但不锁定时长。
- **裁定**：`observe` do 设 `life.dwellUntil = now() + dwellSec*1000`，期间锁定 `currentTarget` 驻留（`vx/vy` 衰减、不漂移）；被**生存级**刺激（`dangerNear`/`hitBy`/`friendHurt`/`friendThreatened`）可打断提前结束；`newThingNear` 不打断。
- **已裁定（2026-08-26 用户拍板）：允许生存级打断，newThingNear 不打断。**

### Q5 · reactionDelaySec 语义坑（延迟期刺激逼近/消失）
- **现役**：`lifeAI`(L1359) 的 `reactUntil` 是全局节流，非"慢性子首刺激延迟"。
- **裁定（必须写死一种）**：命中规则后**锁存首个刺激**（目标+动作），`reactionDelaySec` 期间不行动，到点执行锁存动作；延迟期间若出现**更高优先级 when**（按 `rules` 数组顺序，靠前优先）则**替换锁存**；同优先级不替换；到点时若目标已离开 `sense` 则丢弃（不追出视野）。
- **已裁定（2026-08-26 用户拍板）：锁存首个 + 高优抢占 + 离屏丢弃。**

### Q6 · crowded / personalSpace 精确判定式
- **现役**：无 `crowded` 概念；`personalSpace` 在 `body` 里但零消费者。
- **裁定**：`crowded = count(o | o≠life, dist(o,life) < personalSpace) ≥ CROWDED_N`(=2)。`personalSpace` 直接复用 `body.personalSpace`(px)。**全部生命计入**（含朋友，朋友太多也挤）。
- **已裁定（2026-08-26 用户拍板）：CROWDED_N=2。**

### Q7 · seek 权重如何进入目标选择
- **现役**：`lifeAI`(L1362) "找最近实体" `bd=min(dist)`——无加权。
- **裁定**：替换"最近"为**加权评分**：
  `score(e) = Σ_k  seek[k] * typeMatch(e,k) * (1 - dist(e,life)/sense)`
  其中 `seek[k] ∈ {people,resources,events}`(0–2)，`typeMatch` 命中对应类型=1 否则 0（event 含 `bad_luck`+浪潮+普通 event；`creation/target` 归入 `events`）；取 `score` 最高者为 `bestTarget`。距离归一化 `(1-d/sense)` 使近者权高。
- **已裁定（2026-08-26 用户拍板）：无匹配类型时 fallback 最近。**

### Q8 · 规则评估频率与刺激快照统一
- **现役**：三函数各自独立感知（`decidePersonality` 靠碰撞 `ev`；`lifeWaveReact` 靠 `waveThreat/waveFront`；`lifeAI` 每帧找最近），三套刺激源不统一，student 白板全走默认。
- **裁定**：统一为每帧**一次 `perceive` → 刺激快照**（含 Q1–Q7 全部 when 布尔+目标），再走 〇 章主循环。频率与 `lifeAI` 同（dt 驱动），`reactUntil` 节流保留防抖。
