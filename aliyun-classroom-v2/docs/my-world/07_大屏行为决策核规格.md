## 〇、统一决策核目标架构

```
每帧：
  perceive(life)  ──►  刺激快照（所有 when 词的布尔 + 目标实体）
       │
  if (reactionDelay 锁存中)  ──►  按 Q5 处理延迟，到点执行锁存动作
       │
  否则 遍历 life.behavior.rules（有序，从上到下第一条命中）
       │  rule.when 在快照为真  ──►  执行 rule.do（带目标）
       │
  全不命中  ──►  默认游荡（seek 加权选目标，或随机游荡）
```

- 写死常量全部提升为 `body` 参数插槽：`senseRadius / personalSpace / speedMul / dwellSec / temperSec / reactionDelaySec`。
- `temperSec`（§12.1 已裁）：被 `hitBy` 激怒后 N 秒内，`strangerNear` 自动套用激怒它的那条规则的 `do`。
- 全局 `reactUntil` 节流保留（防抖），但不再承担"慢性子"语义（那是 `reactionDelaySec`，见 Q5）。

## 一、刺激快照（perceive 重写目标）

每帧为 `life` 计算以下 `when` 词的真值 + 目标实体 `bestTarget`：

| when 词 | 快照判定（已裁定） |
|---|---|
| `dangerNear` | 自身 `sense` 内出现 `bad_luck` 或浪潮威胁（waveThreat/waveFront 视为 danger 源） |
| `hitBy` | 本帧被撞/受击（碰撞事件触发，非每帧轮询） |
| `strangerNear` | `sense` 内有生命，但**无 relationship 记录**（Q2 A，纯二元） |
| `friendHurt` | 存在 relationship 伙伴且 `energy < HURT_E`(=30)（Q2 A） |
| `friendThreatened` | relationship 伙伴（自身 `sense` 内）周边 `sense*0.8` 内有 danger（Q1 A） |
| `newThingNear` | `sense` 内有未观察过的 event / creation / 新资源 |
| `crowded` | `personalSpace` 半径内生命数 ≥ `CROWDED_N`(=2)（Q6） |

> 注：资源不进 `when` 词表（06 §5 v1 边界）；贪吃靠 `seek.resources` 表达。`sense = 150 * senseRadius * (1 + perception/100*2)`（沿用现役感知公式，senseRadius 倍率插槽）。

## 二、开口问题拷打（§12.2 应答，全部已裁定）

### Q1 · friendThreatened 扫伙伴半径 → **A（用户拍板）**
只扫自身 `sense` 内伙伴；危险判定用该伙伴周边 `sense*0.8`。远处伙伴顾不上 = 自然（"精但不神"）。

### Q2 · friendHurt / strangerNear 口径 → **A（用户拍板）**
`friend`=有 relationship 记录；`strangerNear`=附近有生命但无记录（纯二元，否掉关系阈值）；`hurt`=伙伴 `energy<30`。零新增系统。

### Q3 · help 目标选取 → **A（用户拍板，推荐）**
多个 hurt 朋友：`score=(100-energy) - dist*k` 取最高 = **最近且最惨优先**。`HELP_GAIN=15` 且**不受 caution 打折**（输能非"吃资源"）。

### Q4 · observe 驻留 → **允许生存级打断（用户拍板）**
`observe` 设 `dwellUntil=now()+dwellSec*1000`，锁 `currentTarget`；被生存级（`dangerNear`/`hitBy`/`friendHurt`/`friendThreatened`）打断；`newThingNear` 不打断。

### Q5 · reactionDelaySec → **锁存首个+高优抢占+离屏丢弃（用户拍板）**
命中规则后锁存首个（目标+动作），延迟期不行动；更高优先级 when（rules 靠前）可替换锁存；同优先级不替换；到点目标离 `sense` 则丢弃。

### Q6 · crowded → **CROWDED_N=2（用户拍板）**
`count(o≠life, dist<personalSpace) ≥ 2`，全部生命计入（含朋友）。

### Q7 · seek fallback → **无匹配 fallback 最近（用户拍板）**
目标选择加权评分 `score(e)=Σ seek[k]*typeMatch(e,k)*(1-dist/sense)`；无匹配类型 fallback 最近，避免呆立。

## 三、7×7 词表 49 格逐格拷打（when 7 × do 7）

判定口径：`do` 的目标解析规则（消除歧义的核心）：
- `flee/retreat/approach/observe` 目标 = 触发该 when 的刺激源（或最近实体）
- `confront` 目标 = 威胁/撞源（仅 `dangerNear`/`friendThreatened`/`hitBy` 提供）
- `gather` 目标 = 附近伙伴（仅 `crowded`/`friend*` 可用）
- `help` 目标 = 受伤朋友（**仅 `friendHurt` 提供**，其余 when 配 help 视为无效降级）

| when \ do | flee | retreat | observe | approach | help | confront | gather |
|---|---|---|---|---|---|---|---|
| **dangerNear** | 复用 cautious 高速逃离 | 新增低速退 | 允许(生存级) | 允许(莽撞) | 无伤友目标→降级 approach | 冲危险源(§12.1) | 聚伴 |
| **hitBy** | 被撞逃 | #8保护者慢退 | 允许(生存级) | 朝撞源(≈confront) | 无伤友目标 | #3冲撞源 | 聚伴 |
| **strangerNear** | 怕生逃 | #1害羞退 | 好奇凑看 | 社交靠近 | help 仅 friendHurt | 好斗迎 | gather 目标=伙伴,非陌生 |
| **friendHurt** | 自私逃 | 退 | 观察 | 靠近 | #1核心,最惨友(Q3) | confront 需威胁源 | 呼救聚 |
| **friendThreatened** | 胆小逃 | 退 | 观察 | 靠近 | help 响应 hurt 非 threat | #8冲威胁源(Q1) | 呼救聚 |
| **newThingNear** | 胆小逃 | 退 | #2好奇驻留(Q4) | 好奇靠近 | 无伤友目标 | 罕见迎 | 聚伴 |
| **crowded** | 怕挤逃 | 退 | 观察 | 爱热闹(矛盾但允) | 无伤友目标 | 罕见迎 | #4社交聚伴 |

**结论**：49 格无未消歧义。所有"do 无对应目标"的组合（help 配非 friendHurt、confront 配无源 when、gather 配陌生）一律降级/无效，由 validator 在行为生成期即拒绝（06 §八白名单不拦但决策核运行期忽略无目标 do）。

## 六、决策核伪代码（runBehavior）

```js
function runBehavior(life, dt){
  if (now() < life.reactUntil) return;            // 全局节流防抖
  const snap = perceive(life);                     // §一 刺激快照（含 Q1/Q2/Q6）

  // —— Q5 reactionDelay 锁存处理 ——
  if (life.delayUntil){
    if (now() < life.delayUntil){
      const hi = firstHigherRule(life, snap);       // 更高优先级 when 命中则替换锁存
      if (hi) { life.lockedRule = hi; life.lockedTarget = snap.target[hi.when]; }
      return;
    }
    if (life.lockedTarget && inSense(life, life.lockedTarget))
      execDo(life, life.lockedRule.do, life.lockedTarget);
    life.delayUntil = 0; life.lockedRule = null; life.lockedTarget = null;
    return;
  }

  // —— 正常规则循环（有序，第一条命中）——
  for (const r of life.behavior.rules){
    if (snap[r.when]){
      const tgt = snap.target[r.when];
      if (life.behavior.body.reactionDelaySec > 0 && tgt){
        life.delayUntil = now() + life.behavior.body.reactionDelaySec*1000;
        life.lockedRule = r; life.lockedTarget = tgt;
      } else if (tgt) execDo(life, r.do, tgt);
      return;
    }
  }

  // —— 全不命中：默认游荡（Q7 seek 加权）——
  wander(life, snap);
}

function execDo(life, do_, tgt){
  switch(do_){
    case 'flee':      fleeFrom(life, tgt); break;            // 高速逃离 + blowUntil
    case 'retreat':   retreatFrom(life, tgt); break;         // 低速拉开(speedMul*0.6)
    case 'observe':   life.dwellUntil = now()+life.behavior.body.dwellSec*1000;
                      life.currentTarget = tgt; observeAt(life, tgt); break;
    case 'approach':  approachTo(life, tgt); break;
    case 'help':      if (dist(life,tgt) < HELP_RANGE) { life.energy += -HELP_GAIN; tgt.energy += HELP_GAIN; playSkillPrimitive(life,'help',{to:tgt}); }
                      else moveToward(life, tgt, life.behavior.body.speedMul); break;
    case 'confront':  moveToward(life, tgt, life.behavior.body.speedMul*1.3); break;  // 逼近刺激源
    case 'gather':    const p = nearestBuddy(life); if (p) moveToward(life, p, life.behavior.body.speedMul); break;
  }
}
```

> `inSense` / `firstHigherRule` / `nearestBuddy` / `wander` 实现细节见 §八。
