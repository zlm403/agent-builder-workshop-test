# 《我的世界》本地调试指南

> 目标：让一个不熟悉本项目的开发者，能独立在本地跑起《我的世界》，调试大屏端与学生端，并理解数据链路。
> 系统：`aliyun-classroom-v2`（Next.js 14 + Prisma + PostgreSQL，试听课三端）
> 目录：`C:\Users\Administrator\Documents\Default Project\aliyun-classroom-v2`

---

## 一、先搞清楚：这不是独立 HTML，是 React 组件

《我的世界》的**大屏画面**和**学生端工作台**是 **Next.js 的 React 组件（TSX）**，不是能双击打开的 HTML 文件。它们跑在 Next.js 应用里，通过 `/student`、`/screen` 两个路由展示。

**能单独改的纯 HTML 文件只有这些**（`public/` 目录）：
- `public/ai-cognition-shift.html` —— A2 认知思考页
- `public/ai-timeline.html` / `four-wings.html` / `pain-wall.html` / `price-reveal.html`

其余大屏/学生端功能都要改 TSX 组件，改完要 **build + 部署**才生效。

## 二、环境准备

### 1. 依赖
```bash
cd C:\Users\Administrator\Documents\Default Project\aliyun-classroom-v2
npm install
```

### 2. 数据库（必需，Next.js 读 PostgreSQL）
- 连接串在 `.env.local` 的 `DATABASE_URL`
- 如果本地没有 PostgreSQL，有两个选择：
  - **A. 连服务器库调试**（最简单）：把 `.env.local` 里 `DATABASE_URL` 指向 `postgresql://classroom_user:Classroom_2026!@8.130.70.114:5432/classroom_db`（⚠️ 会读写线上数据，注意别删数据）
  - **B. 本地起一个 PostgreSQL**，跑 `npx prisma db push` 建表，再 `npx prisma db seed`
- 迁移：`npm run prisma:migrate`（或 `npx prisma db push`）

### 3. AI（可选，不配也能跑）
- 大屏/学生端能跑，但"和 AI 聊"会走规则回退
- 配 key：`LLM_API_KEY=sk-xxx` 写入 `.env.local`（或教师端「设置」里填）

### 4. 启动
```bash
npm run dev
```
- 教师端：`http://localhost:3000/teacher`
- 学生端：`http://localhost:3000/student`
- 大屏端：`http://localhost:3000/screen`

## 三、进入《我的世界》环节（A3_WORLD）

A3（《我的世界》）是课程里的一个模块，接在 A2 之后。要看到它，需要：

1. **教师端**打开 `http://localhost:3000/teacher` → 创建课堂
2. 在「章节」区点 **A3**（或 A2 之后的模块），跳到《我的世界》
3. **大屏**：教师端右上角「打开大屏 ↗」或直接 `http://localhost:3000/screen?sessionId=<课堂ID>`
4. **学生端**：`http://localhost:3000/student?code=<邀请码>`，或用教师端生成的邀请码进入

> 首次进入 A3，世界会自动创建运行数据（`data/world/` 下的 json）。没学生时大屏也有环境光点在飘。

## 四、大屏端调试（WorldScreen.tsx）

**文件**：`src/components/WorldScreen.tsx`

功能：
- Canvas 绘制深海背景、环境光点（鱼缸风格：慢/亮/大/带2字标签）、资源、生命（AI 画的 SVG 形状）、事件光点、碰撞受击闪光
- 2 秒轮询 `/api/world?view=screen`，`requestAnimationFrame` 持续渲染

**调试要点**：
- 光点速度/亮度：教师端「环境光斑」滑杆，或直接改代码里的 `baseSpeed`/`size`/alpha
- 生命形状：AI 生成的 SVG 存在 `world-state.json` 里，改 `drawImage` 那段的绘制方式
- 布局：三栏 grid（左状态/中世界/右动态）

**改完怎么验证**：改 `WorldScreen.tsx` → 浏览器 Ctrl+F5 → 大屏直接看到。

---

## 五、学生端调试（WorldStudent.tsx）

**文件**：`src/components/WorldStudent.tsx`

功能：
- 顶部「当前任务」（同步老师发布的大屏 Tips）
- 创建生命（纯对话：一句话 → AI 生成名字/颜色/形状/定义 → 确认创造 → 进世界）
- 我的生命卡片（能量/行为/原因/关系）
- ✨创作工具 4 按钮（帮我开始/帮我实现/帮我看看/再试一次）
- 💬 和 AI 一起创造（对话）

**调试要点**：
- 学生端需要先进入课堂才有内容（扫码/输码）
- 提交生命 = `POST /api/world/life`（文字→倾向翻译在 `traits.ts`）
- 数据来源 = `GET /api/world?anonymousId=xxx`

---

## 六、世界引擎（engine.ts）

**文件**：`src/lib/world/engine.ts`

- 纯函数模拟：移动/能量/资源/事件/关系/帮助/回避/靠近/休眠
- 惰性推进：每次读 `/api/world` 时按墙钟差补算 tick
- 想调行为参数（能量消耗/速度/半径/倾向），改顶部常量区

**数据流**：
```
学生提交 → /api/world/life → world-lives.json
大屏读   → /api/world → 引擎惰性推进 → world-state.json
世界控制 → /api/world/control（教师端操作）
Tips    → /api/world/popup（大屏弹窗 + 学生端当前任务）
```

## 七、纯 HTML 怎么改（不用 build，改完替换就行）

`public/` 下的 HTML 是静态文件，`next start` 会直接读。

**改认知页例子**：
1. 改 `public/ai-cognition-shift.html`
2. 本地 `http://localhost:3000/ai-cognition-shift.html` 看效果
3. 部署时把这个文件上传到服务器 `/root/classroom-v2/public/` 即可（不用重新 build）

## 八、本地调试 → 部署上线

本地改好、验证后，替换到服务器（阿里云 8.130.70.114:3000）：

### 如果只改了 public/ 的 HTML
```bash
scp public/xxx.html root@8.130.70.114:/root/classroom-v2/public/xxx.html
# 然后进容器
ssh root@8.130.70.114
docker cp /root/classroom-v2/public/xxx.html classroom-v2:/app/public/xxx.html
docker restart classroom-v2
```

### 如果改了 React 组件 / API（必须重新 build）
```bash
# 本地
npm run build   # 确认成功，.next 完整（≥50M，含 server/app）
tar -czf next-full.tar.gz -C aliyun-classroom-v2 .next

# 上传 + 覆盖容器（⚠️ 部署铁律：见 AGENTS.md 六章）
scp next-full.tar.gz root@8.130.70.114:/tmp/next-full.tar.gz
ssh root@8.130.70.114 "bash /tmp/overwrite_next.sh"   # 覆盖 .next + 重启容器
```

> ⚠️ **部署铁律**：生产部署只能走 `/root/classroom-v2/deploy.sh`（唯一入口，带锁）。应急用"本地 .next 覆盖容器"可恢复 404，但事后要登记。详见 `AGENTS.md` 六章 + 根目录 `交接-部署加固任务清单-20260815.md`。

## 九、常见问题

| 现象 | 原因/处理 |
|---|---|
| 大屏中间黑框没光点 | 环境光点 mount 时初始化（不依赖尺寸），检查浏览器缓存，Ctrl+F5 |
| 全部 404 | 容器内 build 残缺 `.next`，用本地完整 .next 覆盖恢复（见第八节） |
| 学生端点创建没反应 | 页面是旧 JS，强刷 |
| "和 AI 聊"没真实回复 | 没配 `LLM_API_KEY`，走规则回退（仍可用） |
| 世界数据乱了 | 删 `data/world/*.json`，下次访问自动重建 |
