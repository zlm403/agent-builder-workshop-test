# 验收标准 V1.0

## 一、功能验收

### 1.1 课堂入场
| 用例 | 预期结果 |
|---|---|
| 教师创建课堂 | 生成 6 位邀请码和二维码 |
| 学生扫码进入 | 进入等待页，显示昵称输入 |
| 输入昵称 + 同意隐私说明 | 分配 anonymousId + resumeToken |
| 断线后重新进入 | 使用 resumeToken 恢复到断线前状态 |
| 重复扫码 | 识别已有会话，不创建新身份 |

### 1.2 教师控制
| 用例 | 预期结果 |
|---|---|
| 推进到下一模块 | 所有学生端同步切换 |
| 跳转到指定模块 | 所有学生端跳转到目标模块 |
| 锁定当前模块 | 学生端显示锁定状态，无法提交 |
| 解锁模块 | 学生端恢复正常操作 |
| 延长倒计时 | 所有端倒计时更新 |
| 暂停/恢复课堂 | 学生端同步暂停/恢复 |

### 1.3 模块引擎
| 用例 | 预期结果 |
|---|---|
| 学生进入模块 | ModuleProgress 状态 = entered |
| 学生提交答案 | ModuleProgress 状态 = submitted，data 写入 |
| 完成条件满足 | ModuleProgress 状态 = completed |
| 完成条件不满足 | 给出明确提示 |
| 教师跳过后 | ModuleProgress 状态 = skipped |

### 1.4 进度追踪
| 用例 | 预期结果 |
|---|---|
| 教师查看全班进度 | 显示每模块完成/进行中/卡住/未开始人数 |
| 教师查看模块详情 | 显示每名学生状态和提交数据 |
| 学生请求帮助 | 教师端显示帮助请求标记 |
| 超时未提交 | 标记为 stuck |

### 1.5 Agent 配置
| 用例 | 预期结果 |
|---|---|
| 学生首次配置 | 创建 AgentProject + AgentConfigVersion(v1) |
| 学生修改配置 | 创建新版本 AgentConfigVersion(v2)，v1 保留 |
| 首次运行 | AIRun 绑定 configVersionId=v1 |
| 二次运行 | AIRun 绑定 configVersionId=v2 |
| 查看前后对比 | 正确关联两个版本和运行结果 |

### 1.6 作品发布与互测
| 用例 | 预期结果 |
|---|---|
| 学生发布作品 | PublishedWork 创建，生成分享码 |
| 选择仅自己可见 | 其他学生不可见 |
| 选择同班匿名可见 | 同班学生可查看，不显示真实身份 |
| 允许教师投屏 | 教师可审核后投屏 |
| 教师审核通过 | publishedWork.screenedBy 记录 |
| 教师撤回作品 | publishedWork.revokedAt 记录 |
| 互测配对 | 系统自动匹配同学作品 |
| 提交互测反馈 | PeerFeedback 记录创建 |

### 1.7 数据导出
| 用例 | 预期结果 |
|---|---|
| 导出课堂总结 | 包含报名人数、实际进入、各模块完成率等 |
| 导出详细数据 (CSV) | 每名学生每模块的完整记录 |
| 导出 AI 日志 | 每次调用的输入摘要、输出、耗时、状态 |
| 学生申请删除 | 匿名化处理，30天内完成 |

## 二、AI 质量验收

### 2.1 输出准确性（使用固定测试集）

| 测试项 | 测试方式 | 通过标准 |
|---|---|---|
| 资料内问题 | 提问资料包含的知识点 | 回答有正确依据，引用可追溯 |
| 资料外问题 | 提问资料不包含的内容 | 明确拒答，不编造依据 |
| 引用完整性 | 检查 citations | 引用片段在原文中真实存在 |
| 输出结构 | 校验 JSON Schema | 100% 通过率 |
| 工作流顺序 | 检查执行步骤 | 按配置顺序执行 |
| 提示词注入 | 提交伪装成系统指令的学生输入 | 不泄露系统信息 |
| 规则生效 | 修改规则后重新测试 | 对应指标确实改善 |
| 难度控制 | 请求不同难度 | 输出难度匹配请求 |

### 2.2 容灾验证

| 测试项 | 预期结果 |
|---|---|
| 首次调用超时 | 同模型重试 |
| 格式不合法 | 格式修复 → 重试 |
| 主模型连续失败 | 切换备用模型 |
| 全部模型不可用 | 返回明确错误 + 教师可开演示模式 |
| 演示模式标注 | 所有输出标注"演示模式" |
| 并发超过上限 | 排队处理，不丢失请求 |

### 2.3 事实核验

| 测试项 | 预期结果 |
|---|---|
| 引用片段匹配 | 粗匹配 + 语义匹配都通过 |
| 知识点映射 | 输出中的知识点能映射到资料 |
| 外源检测 | outsideSource 字段准确标记 |
| 必填字段 | 所有要求字段存在且非空 |
| 字数检查 | 输出字数在规则范围内 |

### 4.2 A/B 对比指标

#### 第一层：课堂是否成立

**A 版标准：**
- 80% 以上完成第一次运行
- 60% 以上完成一次修改
- 50% 以上发布作品
- 70% 以上能说出岗位、资料、规则、流程

**B 版标准（后续验证）：**
- 80% 以上至少完成两个案例
- 70% 以上完成三个案例共同结构题
- 60% 以上生成个人机会地图
- 50% 以上确定一个行动方向

## 五、隐私与合规验收

| 检查项 | 标准 |
|---|---|
| 学生使用匿名 ID | 默认不收集真实身份 |
| 昵称与作品独立授权 | 分别 consent |
| 默认作品仅自己可见 | 不自动公开 |
| 投屏需展示授权 | ConsentRecord.screen_display = true |
| 文件自动删除 | 设定保留周期 |
| 日志不保存敏感内容 | 脱敏处理 |
| 审计日志完整 | 教师操作、模型切换、审核 |
| 学生可申请删除 | DELETE API + 处理流程 |
| 不强制收集联系方式 | 报名环节可选 |
| 课堂数据不直接用于营销 | 需额外同意 |

## 六、安全检查清单

| 检查项 | 标准 |
|---|---|
| 学生资料不视为系统指令 | 分层传递 |
| 限制资料长度 (< 50000字) | API 层限制 |
| 限制文件类型和大小 | 上传层限制 |
| 昵称安全审核 | moderate_content |
| 输入安全审核 | 防注入、敏感词 |
| AI 输出安全审核 | moderate_content |
| 学生不可修改系统 Prompt | 不暴露接口 |
| 不暴露模型密钥 | 后端代理 |
| SQL 注入防护 | Prisma 参数化查询 |
| XSS 防护 | React 默认转义 + CSP |
| CSRF 防护 | SameSite Cookie + Token |
