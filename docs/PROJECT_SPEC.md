# AI Agent 互动试听课系统 — 项目规格书 V1.0

## 一、项目定义

### 1.1 系统定位

系统不是一个"HTML 版 PPT"，也不是开放聊天工具，而是一个**由教师控制、学生实时参与、AI 在受控流程内执行的课堂系统**。

### 1.2 方案 A 课堂目标

学生在 120 分钟内完成一个资料型 Agent 的：定义 → 配置 → 首次运行 → 故障测试 → 修改 → 二次运行 → 发布。

### 1.3 学生最终获得

| 产出物 | 类型 |
|---|---|
| 可运行的基础 Agent | 运行时实例 |
| 结构化 Agent 配置 (V1 + V2) | JSON |
| 首次测试结果 | 结构化记录 |
| 修改后结果 | 结构化记录 |
| 前后对比报告 | 可视化页面 |
| 可分享作品页面 | URL + 二维码 |

### 1.4 教师最终获得

- 全班实时进度面板
- 每个环节的参与数据
- 可审核、可投屏的学生作品
- AI 调用和异常记录
- 报名及后续教学分析数据

## 二、系统边界

### 2.1 V1 实现范围

| 功能 | 说明 |
|---|---|
| 课堂创建 + 二维码 | 教师创建课堂，生成入场二维码 |
| 匿名入场 | 学生通过手机/平板/电脑扫码进入 |
| 教师环节控制 | 推进、跳转、锁定教学模块 |
| 学生任务交互 | 投票、配置、测试、发布 |
| 统一 AI 调用 | 后端代理，学生不接触模型密钥 |
| 状态持久化 | 每名学生每步状态保存 |
| 实时进度 | 教师端实时查看完成/卡住人数 |
| 作品投屏 | 教师审核后选择作品投到大屏 |
| AI 输出校验 | 结构校验、规则检查、安全审核 |
| 容灾降级 | 重试 → 切换模型 → 演示模式 |
| 数据导出 | 课后导出匿名教学数据 |

### 2.2 V1 暂不实现

- 任意类型 Agent 自由开发
- 多 Agent 协作
- 外部工具市场
- 长期记忆
- 复杂向量知识库
- 手机端自由节点拖拽
- 学生自行配置模型 API
- 公开互联网作品社区
- 自动支付和复杂 CRM

## 三、四个使用端

### 3.1 教师导演台

| 能力 | 优先级 |
|---|---|
| 创建/复制/开始/暂停/结束课堂 | P0 |
| 选择课程版本 A 或 B | P0 |
| 查看全部教学模块并任意跳转 | P0 |
| 开启/关闭/锁定学生任务 | P0 |
| 查看每关完成和卡住人数 | P0 |
| 延长倒计时 | P1 |
| 查看学生提交内容 | P0 |
| 审核并选择作品投屏 | P0 |
| 切换主模型/备用模型/演示模式 | P1 |
| 导出课堂数据 | P1 |

### 3.2 学生移动端

| 能力 | 优先级 |
|---|---|
| 扫码进入 + 昵称 + 隐私说明 | P0 |
| 自动跟随教师当前环节 | P0 |
| 断线重连和进度恢复 | P0 |
| 选择/短文本/规则配置/流程排序 | P0 |
| 运行 AI 任务并查看执行状态 | P0 |
| 诊断结果 → 修改规则 → 再次运行 | P0 |
| 发布和分享作品 | P0 |
| 自愿提交联系方式 | P1 |

### 3.3 课堂大屏

大屏与教师控制台分离，只展示适合投影的内容：
- 当前问题和教学内容
- 学生进入人数、完成率、倒计时
- 匿名投票和提交结果
- 经教师审核的学生作品
- 修改前后对比
- **不显示**：手机号、学号、文件原文、模型系统提示词

### 3.4 运营管理端 (V1 简化版)

- 课程模板管理
- 案例资料管理
- 知识库版本管理
- Prompt 与 Skill 版本管理
- 模型配置和调用额度
- 敏感词及内容审核规则
- 课堂数据查询和导出
- 数据保留周期和删除功能

## 四、方案 A 模块流程 (14 模块)

| 模块 ID | 名称 | 默认时长 | 学生任务 | 完成条件 |
|---|---|---|---|---|
| A00 | 入场 | 5min | 昵称、隐私授权 | 获得匿名学生 ID |
| A01 | 基线调查 | 5min | AI 使用经验与 Agent 认知 | 完成 3 个问题 |
| A02 | 结果挑战 | 10min | 比较普通 AI 与 Agent 结果 | 完成 4 项评分 |
| A03 | 结构拆解 | 10min | 识别岗位/资料/规则/流程 | 配对题正确率达标 |
| A04 | 定义任务 | 10min | 选择 Agent 类型并描述目标 | 任务描述通过检查 |
| A05 | 添加资料 | 10min | 示例资料或粘贴短资料 | 资料解析成功 |
| A06 | 设置规则 | 10min | 来源/边界/格式/反馈 | 至少配置 4 条规则 |
| A07 | 配置流程 | 10min | 排列工作步骤 | 形成有效执行顺序 |
| A08 | 首次运行 | 8min | 完成一次真实交互 | 获得结构化结果 |
| A09 | 故障测试 | 10min | 资料内/外/模糊请求测试 | 完成 3 类测试 |
| A10 | 诊断修改 | 10min | 标记问题并修改至少一条规则 | 形成配置 V2 |
| A11 | 二次运行 | 7min | 使用同一测试再次运行 | 获得可比结果 |
| A12 | 发布互测 | 8min | 发布作品 + 接受同学反馈 | 发布且收到反馈 |
| A13 | 路径报名 | 7min | 查看能力报告和正式课路径 | 完成反馈或报名动作 |

> 时间可由教师调整，系统保留默认时间与超时提示。
