# Sprint 开发计划 V1.0

## 总览

| Sprint | 周期 | 目标 | 交付内容 |
|---|---|---|---|
| Sprint 1 | 第1周 | 共用课堂底座 | 课堂创建、二维码入场、模块引擎、教师推进、进度追踪、大屏框架 |
| Sprint 2 | 第2-3周 | 方案A核心闭环 | 任务定义、资料处理、规则配置、流程排序、AI运行、诊断、修改 |
| Sprint 3 | 第4周 | 作品与控制 | 前后对比、作品卡、审核投屏、互测、模型降级、限流、日志、导出 |
| Sprint 4 | 第5周 | 内部彩排 | 50人模拟、弱网测试、故障演练、修复 |
| Sprint 5 | 第6周+ | 正式测试 | A/B各跑1-2场，数据收集 |

---

## 风险与依赖

| 风险 | 缓解措施 |
|---|---|
| AI 模型稳定性不可控 | 五步容灾 + 预生成示例 |
| 现场网络环境复杂 | 弱网优化 + 重连机制 |
| 50人并发压力 | Redis + 连接池 + 限流 |
| 内容审核误杀 | 人工审核兜底 + 申诉 |
| B 版内容尚未确定 | 先做共用底座，B 版接口预留 |
