# 课程方案：从观众到导演（6小时）

> 定位：6小时，亲手做出3个能发布的作品——一个游戏、一个工具、一个懂你的AI。
> 平台：轻雾APP编写 → 一键发布到平台，别人登录即可使用。
> 形式：小班面授，一人一台笔记本。

---

## 表一：课程框架（6小时，做什么）

**上午 3 小时**

| 时间 | 环节 | 项目 | 干什么 |
|---|---|---|---|
| 0-30min | 开场·熟悉环境 | — | 登录轻雾、打开示例项目、学会"打开/运行/预览" |
| 30-90min | 项目一 | **小游戏**（接金币/打地鼠/躲避球，自选） | 一句话做成→跑→改→上传，练完整闭环 |
| 90-105min | 休息 | | |
| 105-180min | 项目二 | **心情电量** | 记录心情→存起来→画出电量曲线+小结 |

**下午 3 小时**

| 时间 | 环节 | 项目 | 干什么 |
|---|---|---|---|
| 0-15min | 开场·衔接 | — | 回顾上午，演示下午成品（一个很懂你的AI） |
| 15-105min | 项目三（上） | **内心戏** | 搭骨架：人设+界面+接入内置AI；演示AI自己干活 |
| 105-120min | 休息 | | |
| 120-165min | 项目三（下） | **内心戏** | 让它读懂你：观察、复述、把你说不出的话讲出来 |
| 165-180min | 收尾·发布 | — | 发布到平台、互相体验作品、认知收束 |

## 表二：知识点框架（六类教什么，主要落在哪）

| 类 | 教什么 | 主要落在 |
|---|---|---|
| 沟通指挥类 | 照着做 / 先做最小的 / 做之前先问我 / 分步走 / 列表格 / 让AI帮你说清楚 / 复述确认 / 贴图 | 贯穿全天，项目三深化 |
| 项目推进类 | 模糊想法→多方案→拆第一步→中途问进度→卡住先暂停 | 项目三为主 |
| 工具操作类 | 打开/运行/预览、装/用Skill、建/用知识库、用Agent、跑起来+分享 | 上午开头+全程 |
| 容错纠错类 | 先规划再动手、AI会错很正常、demo验收、把错说清楚、让它改、再跑、重开 | 项目一+项目三 |
| 安全保障类 | 保存、回退、撤回、知道在哪操作、看不懂的文件别删 | 项目二 |
| 记忆续接类 | 装记忆插件、AI会记住、续接进度、控制上下文 | 项目二+项目三 |

说明：六类知识**不单独讲，全部长在三个项目里**——做完即学会。有的知识横跨多个项目，所以不硬拆。

---

## 介绍稿（"推"·可直接用）

> **《从观众到导演：6小时，亲手做出3个能发布的作品》**
>
> 上午，你做一个**能玩的游戏**，学会"让AI听你的话"；
> 再做一个记录心情的**「心情电量」**，学会"让一个想法真正落地"；
> 下午，你创造一个懂你的AI——**「内心戏」**，它听你说、感觉你，把你没说出口的话讲给你听。
>
> 每一个作品，都会发布到我们的平台上——**任何一个人登录，都能玩你的游戏、用你的工具、和你的AI聊天。**
>
> 我们不教编程，教的是AI时代做事的方法：**会问、会改、会救、会发。**
> 6小时，从AI的观众，变成AI的导演。
