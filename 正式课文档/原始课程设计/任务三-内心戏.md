# 任务三教案：内心戏（懂你的 AI）

> 课程名称：从观众到导演
> 课程阶段：下午项目三（综合 AI 应用，独立 3 小时）
> 建议用时：下午 3 小时（含开场衔接 15min + 休息 15min + 收尾 15min，教学约 150min）
> 适用对象：已完成任务一（闭环）、任务二（落地/有退路/接得上）的学生
> 核心平台：轻雾 / 顷悟
> 任务类型：综合 AI 应用（人设 + 界面 + 接入 AI + 可插拔功能 + Agent 协作）

---

## 一、任务定位

任务三是三个项目里最综合的一个。前两个是"游戏"（练闭环）和"工具"（练落地），任务三是**一个完整的 AI 应用**——一个"懂你的 AI"。

它为什么难、为什么复杂：
- 前两个项目，AI 是"帮你做东西"的助手；
- 任务三里，**AI 本身就是要做的作品**——它有性格、会观察你、能复述你、甚至把你没说出口的话讲出来。

**本任务的核心新概念：可插拔基础组件。**

> 用一个"插座"来理解：基础（人设+界面+接 AI）= 插座；各种功能（记住你/画风切换/心情识别/回忆记录）= 插头。
> 插进去 → 功能生效，且不干扰其他；拔出来 → 功能关闭，其他不受影响；数据接口一关 → 连接断开，基础照常跑。

这就是软件世界"插件化"的结构——**基础稳定、功能可插拔**。这个结构概念是任务三要建立的核心。

**另外体验的**：Agent（让 AI 自己干活）、Skill（给 AI 装技能）、多 Agent 协作（多个 AI 分工）、**抄作业**（找别人做好的 skill/知识库来用——从头创造很难，会借力很重要）。

---

## 二、教学目标

### 1. 知识目标

学生理解：
- 什么是"综合 AI 应用"（人设 + 界面 + 接入 AI + 可插拔功能）；
- 什么是"可插拔基础组件"（基础稳定、功能插拔、数据接口开关）；
- 什么是 Agent（能独立干活的 AI）；
- 什么是 Skill（给 AI 装技能包）；
- 什么是多 Agent 协作（多个 AI 分工）；
- 为什么"抄作业"（复用现成 skill/知识库）是高效做法，去哪找、怎么用。

### 2. 操作目标

学生能够：
- 定义 AI 的人设（它是谁、懂什么、边界在哪）；
- 搭建骨架（人设 + 界面 + 接入内置 AI）；
- 做一个可插拔功能（插入生效、拔出不影响、数据接口可关）；
- 装一个 Skill 并触发；
- 用 Agent 独立完成一个任务；
- 让 AI 观察、复述、说出用户没说出口的话；
- 让多个 Agent 分工协作；
- 找一个现成的 skill/知识库并接入自己的应用；
- 调整版面布局；
- 发布并互玩。

### 3. 能力目标

学生形成：
- "基础 + 插件"的结构思维（不是一锅粥，是稳定基础 + 可插拔功能）；
- 借力思维（先找现成的，再自己造）；
- 综合指挥能力（人设描述、边界设定、多 Agent 分工）；
- 独立完成一个完整 AI 应用的能力。

### 4. 认知目标

学生感受到：
- 做一个"懂你的 AI"比做游戏/工具更考验"把话说清楚"（人设/边界）；
- 会借力（找现成 skill/知识库）不是抄作业丢人，是聪明的做法；
- 复杂系统靠"可插拔结构"才能稳定又灵活。

---

## 三、学生最终作品标准

每位学生完成一个"内心戏"AI 应用——一个懂你的 AI。

### 1. 必须具备的功能（基础骨架）
- AI 有人设（名字、性格、它是谁）；
- 有界面（对话区 + 至少一个展示区）；
- 接入内置 AI，能对话；
- 能"复述"用户说的话（确认它听到了）；
- 能根据用户输入做一句"读懂你"的回应（把没说出口的感觉讲出来）；
- 至少一个可插拔功能（插入生效、拔出不影响）。

### 2. 可插拔功能（学生可选，可多装）
- 记住你（记忆插件，说过一次记得）；
- 心情识别（从话里判断情绪）；
- 画风切换（换个界面风格）；
- 回忆记录（把聊过的存下来）；
- 每日小结（一天结束给你一句话）；
- 多 Agent（一个观察你、一个回应你、一个写小结）。

### 3. 学生可以自定义的内容
- AI 人设（名字/性格/职业/口头禅）；
- 界面主题、颜色、布局；
- 回应风格（温柔/犀利/幽默/诗性）。

### 4. 抄作业（复用）
- 至少接入一个**别人做的 skill 或知识库**（从顷悟技能市场/知识库广场/同学那找）。

> 先搭好基础骨架（人设+界面+接AI），再插功能，最后抄作业 + 多 Agent。

---

## 四、教学重点

- 建立"可插拔基础组件"的结构概念；
- 让人设/边界"说得清楚"（AI 是谁、懂什么、不做什么）；
- 体验 Agent（AI 自己干活）；
- 装 Skill 并触发；
- 让 AI"读懂你"（观察→复述→把说不出的话讲出来）；
- 多 Agent 协作（分工）；
- 抄作业（找现成 skill/知识库：在哪找、怎么用）；
- 版面布局调整。

---

## 五、教学难点与注意点

### 1. 学生容易把"人设"说得很笼统
- 现象："做一个温柔的 AI"。
- 处理：追问具体——它是谁？对谁温柔？什么事会生气？绝不做什么？

### 2. 学生容易把功能做成"写死"，不是"可插拔"
- 现象：加了功能就把基础改坏了，或功能间互相干扰。
- 处理：强调"插座结构"——基础不动，功能是独立插头，数据接口单独开关。

### 3. 学生不知道"可插拔"有什么用
- 处理：演示——插一个功能进去（生效），拔出来（关闭），其他功能照常。让学生感受"稳定基础 + 灵活功能"。

### 4. 学生不会找现成的 skill/知识库
- 处理：带学生到顷悟技能市场/知识库广场搜关键词（"记忆""情绪""绘画"），装一个试试。

### 5. 多 Agent 协作容易乱
- 处理：先给明确分工（A 观察、B 回应、C 小结），每个 Agent 只干一件事，先小范围试。

### 6. 对话太长（综合应用最容易）
- 处理：分段做，做完一步存进度；对话卡了就开新会话让 AI 读进度继续。

### 7. 时间不足
- 删减顺序：先砍"多 Agent"，再砍"版面布局"，保留"基础骨架 + 一个可插拔功能 + 读懂你 + 抄作业"。

# 八、详细教学步骤

## 阶段一：开场·衔接（0-15min）

### 教师步骤
1. 回顾上午：游戏（闭环）、工具（落地）。
2. 演示下午成品——一个"懂你的 AI"：它听你说，观察你，复述你，把你没说出口的话讲出来。
3. 抛出任务："下午我们创造一个 AI，它是你的作品。"

### 学生步骤
1. 体验老师演示的 AI。
2. 理解：今天 AI 不是助手，是作品本身。

### 教师话术
> "上午 AI 帮你做东西，下午你要做的，就是一个 AI 本身。它懂你——你得先让它听懂你。"

### 阶段产出
学生理解任务三目标。

---

## 阶段二：任务引入·可插拔基础组件（15-30min）

### 教师步骤
1. 用"插座"类比讲清结构：
   - 插座（基础）：人设 + 界面 + 接 AI；
   - 插头（功能）：记住你 / 心情识别 / 画风切换...
   - 插进去生效、拔出来关闭、数据接口可单独开关，基础照常跑。
2. 现场演示一次插/拔（给全班看：插一个功能生效，拔掉不影响别的）。
3. 说明：今天你的 AI 就按"基础 + 可插拔"来搭。

### 学生步骤
1. 记住"插座结构"：基础稳定，功能可插拔。
2. 在任务卡上写下：我的基础是什么、我要插哪些功能。

### 教师话术
> "记住这个结构：基础稳定，功能可插拔。插进去不影响别人，拔出来不影响基础，数据接口一关，连接就断。这是软件世界最重要的结构。"

### 阶段产出
学生理解可插拔概念，任务卡写好基础/功能清单。

---

## 阶段三：定人设（30-45min）

### 教师步骤
1. 示范把人设说清楚：名字/性格/职业/对谁/生气什么/绝不做什么。
2. 让学生写人设。

### 学生提示词

```text
我要做一个 AI，它的名字叫__________。
它是__________（性格/职业/口头禅）。
它面对__________（谁）时__________。
它最容易__________（生气/关心/共情）。
它绝不__________（边界，比如不评价、不催作业）。

请先复述你理解的人设，再帮我把它变成 AI 的"性格说明"。
```

### 学生步骤
1. 填人设。
2. 让 AI 复述，检查人设对不对。
3. 确认人设。

### 本阶段知识点
- 给参照 / 先做最小 / 复述确认 / 边界。

### 阶段产出
人设定稿，AI 复述正确。

---

## 阶段四：搭骨架（45-75min）

### 教师步骤
1. 示范搭骨架三件事：人设（上面做好了）+ 界面（对话区+展示区）+ 接入内置 AI。
2. 提醒先跑通"能对话"再丰富。

### 学生提示词

```text
现在搭骨架：
1. 用我确定的人设；
2. 做一个界面：一个对话区 + 一个展示区（显示 AI 的回应和"它听到的"）；
3. 接入内置 AI，能对话；
4. 先做最小能用的版本，别加复杂功能。

请先复述你的搭建计划，再实现。
```

### 学生步骤
1. 发指令，让 AI 搭骨架。
2. 打开运行，测试：能和 AI 对话吗？展示区显示吗？
3. 验收表记录。

### 本阶段知识点
- 复述确认 / 先做最小 / 打开运行预览 / 做完问进度。

### 阶段产出
一个能对话的 AI 基础骨架。

---

## 阶段五：可插拔功能（75-105min）

### 教师步骤
1. 演示：做一个可插拔功能（比如"记住你"），插入生效、拔出不影响、数据接口单独开关。
2. 让学生把功能做成"独立插头"，不写死在基础里。

### 学生提示词（以"记住你"为例）

```text
请给 AI 加一个可插拔功能："记住你"。

要求：
1. 它是个独立功能，不改变基础对话；
2. 用户说"我叫小华"后，AI 记住并下次用；
3. 可以关闭这个功能（数据接口开关），关闭后基础对话照常；
4. 只做这一个功能，不碰其他。

请先复述你的实现方案（怎么插、怎么拔、接口怎么关），再实现。
```

### 学生步骤
1. 选一个功能（记住你/心情识别/画风切换/回忆记录）。
2. 让 AI 做成可插拔。
3. 测试三件事：插入生效吗？拔掉不影响别的吗？接口关闭基础照常吗？
4. 验收表记录。

### 本阶段知识点
- 可插拔结构（核心）/ 一次一小步 / 列表格 / 先做最小。

### 阶段产出
一个可插拔功能，插入/拔出/开关都验证通过。

---

## 阶段六：Agent + Skill（120-135min，休息后）

### 教师步骤
1. 讲：Agent = 能独立干活的 AI（给它任务自己拆自己干）；Skill = 给 AI 装技能包。
2. 演示：装一个 Skill（触发语），让 Agent 独立完成一个任务（如"整理聊天记录"）。
3. 带学生装一个 Skill、让 Agent 干一件事。

### 学生操作
1. 到顷悟技能市场装一个 Skill（如"整理""情绪""绘画"）。
2. 触发它：跟 AI 说"用 xxx skill 帮我做 xxx"。
3. 体验 Agent：给 AI 一个任务，看它自己拆解完成。

### 学生提示词

```text
用我装好的 skill，帮我做一件事：__________。
请你自己拆解步骤，独立完成，完成后再问我下一步。
```

### 本阶段知识点
- 装/用 Skill / 用 Agent / 拆第一步。

### 阶段产出
装好至少 1 个 Skill，体验了 Agent 独立干活。

---

## 阶段七：让它读懂你（135-150min）

### 教师步骤
1. 讲三层：观察（它听你的话）→ 复述（它确认听懂）→ 把说不出的话讲出来（它共情）。
2. 示范：让 AI 复述你说的话，再让它讲出你没说出口的感觉。

### 学生提示词

```text
现在训练 AI 读懂我：
1. 我说话后，它先复述我听到的内容；
2. 然后它说出我可能没说出口的感觉/需求（用"我猜你..."开头）；
3. 保持人设，不评价不催作业。

请先复述你的实现方式，再改。
```

### 学生步骤
1. 让 AI 具备"复述 + 讲出没说出口的话"。
2. 测试：说一段话，看它复述对吗？说出的感觉准吗？
3. 不准就用三要素让 AI 改。

### 本阶段知识点
- 复述确认 / 把话说清 / 贴图（可说"你看我这段话"）/ 共情表达。

### 阶段产出
AI 能复述你、并说出你没说出口的感觉。

---

## 阶段八：多 Agent 协作 + 抄作业（150-165min）

### 教师步骤
1. 讲多 Agent 协作：多个 AI 分工（一个观察你、一个回应你、一个写小结），每个只干一件事。
2. 带学生做一个简单多 Agent 协作。
3. **抄作业**：到顷悟技能市场/知识库广场/同学那，找一个现成 skill 或知识库，接入自己的应用。

### 学生操作（多 Agent）

```text
让三个 Agent 协作：
Agent 观察：听你说，记录你的关键词；
Agent 回应：根据人设回应你；
Agent 小结：每次对话结束，写一句话小结。
每个 Agent 只做一件事，互不干扰。
```

### 学生操作（抄作业）
1. 到顷悟技能市场 / 知识库广场搜关键词（"记忆""情绪""绘画""日记"）。
2. 找一个现成的 skill 或知识库。
3. 装进/接入自己的应用，试一下好不好用。
4. 在任务卡记下：我找了什么、在哪找的、怎么用的。

### 本阶段知识点
- 多 Agent 协作 / 拆第一步 / 借力（抄作业）/ 装用Skill/建用知识库。

### 阶段产出
体验了多 Agent 分工；抄了一个现成 skill/知识库并接入。

---

## 阶段九：发布互玩·收束（165-180min）

### 教师步骤
1. 组织保存、发布、互玩。
2. 认知收束：从观众到导演——会问、会改、会救、会发、会借力、会搭结构。

### 学生步骤
1. 保存可运行版本。
2. 发布，互玩同学的作品。
3. 填进度记录。

```text
我的 AI 名字：__________
它的人设：__________
我插的可插拔功能：__________
我抄的 skill/知识库：__________
```

# 十、知识点清单

## 1. 沟通指挥类（深化）
- 人设/边界说清楚（AI是谁/懂什么/绝不做什么）；
- 复述确认（让AI复述人设/方案）；
- 列表格（功能清单）；
- 一次一小步（先骨架后功能）。

关键句：
```text
请先复述你理解的人设/方案。
```

## 2. 项目推进类（综合）
- 拆第一步（搭骨架=人设+界面+接AI）；
- 问进度；
- 卡住暂停。

## 3. 工具操作类（重点加深）
- 装/用 Skill（重点）；
- 建/用知识库（重点）；
- 用 Agent（重点）；
- 打开/运行/预览/发布；
- 版面布局调整。

## 4. 容错纠错类
- 三要素描述问题；
- 让 AI 只改一处；
- 改完重跑；
- 抄来的东西不对就换/修。

## 5. 安全保障类
- 改前保存；
- 回退；
- 不删看不懂的文件（抄来的文件先搞懂再动）。

## 6. 记忆续接类
- 续接进度（综合应用对话长，最需要）；
- 控制上下文（开新会话读进度）；
- AI会记住（记忆插件）。

# 十一、学生自救流程

1. 说清卡点（做什么/希望/实际）；
2. 查自救知识库；
3. 问 AI；
4. 同桌互助 30 秒；
5. 再喊老师（带：试了什么/查了什么/AI说了什么/还卡在哪）。

# 十二、分层教学策略

### 1. 基础层
给完整模板（人设/骨架/一个可插拔功能/复述），用现成 skill。完成"能对话 + 复述 + 一个可插拔功能"。

### 2. 标准层
完成：人设 + 骨架 + 可插拔功能 + 装 skill + 读懂你 + 抄一个作业 + 发布。

### 3. 挑战层
加多 Agent 协作 + 多个可插拔功能 + 版面布局打磨 + 自造一个小 skill。

# 十三、课堂评价

| 维度 | 1 | 2 | 3 |
|---|---|---|---|
| 人设表达 | 只会说"温柔" | 能说清性格 | 能说清是谁/懂什么/边界 |
| 可插拔结构 | 功能写死 | 能插能拔 | 插拔/接口开关都验证过 |
| Agent/Skill | 没装 | 装了触发 | 装+触发+让Agent独立干活 |
| 读懂你 | 不复述 | 能复述 | 复述+说出没说出口的话 |
| 多Agent | 没做 | 有分工 | 分工明确互不干扰 |
| 抄作业 | 没找 | 找了 | 找到并接入自己应用 |
| 问题描述 | 只说"坏了" | 三要素 | 三要素+让AI只改一处 |
| 完成度 | 不能用 | 能对话 | 能发布、有可插拔功能、抄过作业 |

巡堂快检：
> "你的 AI 能复述我吗？插一个功能试试，拔掉别的功能还正常吗？"

# 十四、常见问题与处理方法

### 问题一：人设太笼统
处理：追问"它对谁温柔？什么事会生气？绝不做什么？"

### 问题二：功能写死、不可插拔
处理："功能要像插头，独立、能拔、不影响基础。数据接口单独开关。"

### 问题三：不会找现成 skill/知识库
处理：带学生到顷悟技能市场/知识库广场搜关键词，装一个试。

### 问题四：多 Agent 乱
处理：每个 Agent 只干一件事，先分工明确，再协作。

### 问题五：对话太长卡住
处理：分段做，做完存进度；开新会话让 AI 读进度继续。

### 问题六：抄来的东西不好用
处理：先搞懂它是干嘛的，不好用就换一个，别硬改看不懂的。

# 十五、课后沉淀

学生填"我的救命记录"（AI名/人设/可插拔功能/抄的skill/卡点/作品链接/下次第一步）。

教师让 AI 写成长报告：
```text
请根据我下午做内心戏的记录，总结：我搭了什么结构、用了哪些AI协作方法、抄了什么、多Agent怎么分工的、卡在哪、下次改进什么。重点评价我的过程和方法。
```

# 十六、教师收束语

> "今天你做的不是一个小游戏、一个小工具，而是一个完整的 AI 应用——它有性格、能复述你、甚至说出你没说出口的话。"

> "你学到的三件大事：一，复杂系统靠'可插拔结构'——基础稳定，功能插拔；二，会借力——找到别人做好的 skill 和知识库，比自己从头造快得多；三，综合指挥——人设、边界、Agent、多 Agent，你都能让它按你的想法转。"

> "从观众到导演：上午你让 AI 帮你做游戏，下午你创造了一个 AI。三件作品，就是你 6 小时的证据。"

# 十八、任务完成判断

学生能：
1. 用一句话说清 AI 的人设和边界；
2. 让 AI 复述过需求和方案；
3. 搭出能对话的基础骨架；
4. 做一个可插拔功能（插入/拔出/接口开关验证过）；
5. 装了一个 Skill 并触发；
6. 体验了 Agent 独立干活；
7. 让 AI 复述你、说出你没说出口的话；
8. 体验过多 Agent 分工；
9. 抄了一个现成 skill/知识库并接入；
10. 改前保存、改坏能回退；
11. 发布/分享作品；
12. 填了进度记录。

> 作品可以不完美，但学生必须经历"搭结构、插功能、用Agent、抄作业、让AI读懂你、发布"的完整过程。
