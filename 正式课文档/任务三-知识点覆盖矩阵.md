# 任务三 · 知识点覆盖矩阵（隐藏线）

> **用途**：任务三表面是做一个"懂你的 AI"（内心戏），隐藏线是建立**可插拔基础组件结构** + 体验 **Agent/Skill/多Agent/抄作业（借力）**。本矩阵把下午 3 小时每个阶段 ↔ 知识点 ↔ 学生动作 ↔ 系统检测。
> **配套**：《任务三教案-内心戏.md》、《正式课知识点分类表.md》、《判断skill知识库.md》。
> **对应关系**：任务三 = 项目三（内心戏），course 编码 4。

---

## 一、任务三覆盖的知识点（综合 + 新概念）

| 类 | 知识点 | 任务三定位 |
|---|---|---|
| ① 沟通指挥 | 给参照/先做最小/先问再动手/一次一小步/列表格/复述确认/边界 | ✅ **综合深化**（人设/边界说得清） |
| ② 项目推进 | 拆第一步/问进度/卡住暂停 | 🟡 综合应用 |
| ③ 工具操作 | **装/用Skill、建/用知识库、用Agent**、打开运行预览、跑起来分享、**版面布局** | ✅ **重点（本任务核心体验）** |
| ④ 容错纠错 | 三要素/让它改/改完再跑/抄来的不对就换 | 🟡 综合 |
| ⑤ 安全保障 | 先存/回退/不删看不懂的（抄来的文件先搞懂） | 🟡 综合 |
| ⑥ 记忆续接 | 续接进度/控制上下文/AI会记住 | ✅ **综合应用最需要**（对话长） |

**新概念（非六类，但本任务核心）**：
- 可插拔基础组件（基础稳定、功能插拔、数据接口开关）；
- 多 Agent 协作（多个 AI 分工）；
- 抄作业（复用现成 skill/知识库：在哪找、怎么用）。

## 三、任务三隐藏线总结

```
表面（学生看到）：做一个懂你的AI（内心戏）
隐藏线（实际学到）：
  新结构：可插拔基础组件（基础稳定/功能插拔/数据接口开关）
  新体验：Agent（AI自己干活）/ Skill（装技能）/ 多Agent协作（分工）
  新能力：抄作业（找现成skill/知识库：在哪找、怎么用）
  ① 深化：人设/边界说得清
  ③ 加深：装用Skill/建用知识库/用Agent/版面布局
  ⑥ 最需要：续接进度/控制上下文（综合应用对话长）
```

**任务三结束时，学生建立"可插拔结构"思维 + 会借力 + 会综合指挥**——这是"导演"的核心。

---

## 四、老师怎么用这张表

1. **课前**：确认"可插拔结构 + Agent/Skill + 抄作业"是本任务新增核心；
2. **课中**：每阶段看学生行为，重点查"插拔验证了吗、装skill触发了吗、抄到了吗"；
3. **课后**：复盘全班可插拔/借力概念是否建立，这是认知收束的关键。

> 系统配合：water-analyzer 学习水位覆盖六类；任务三重点看 ①③⑥ 水位 + 可插拔/多Agent/抄作业行为信号。
