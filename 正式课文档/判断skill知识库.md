# 课堂诊断 · 判断 Skill 知识库（草稿）

> 用途：给"判断 skill"当标尺。skill 读学生与 AI 的对话，对照本知识库，判断学生卡在哪个知识点、属于全班性问题还是个人问题。
> 底座来源：《课程方案.md》（三项目结构）+《正式课知识点分类表.md》（六大类知识点）。
> 状态：**草稿**，待张老师校正。改动本项目时同步更新《文档索引.md》。

---

## 一、项目结构（学生当前在哪个环节）

> 用于定位"他正在做什么"。

| 项目 | 环节 | 学生要完成的事 | 对应旧四课 |
|---|---|---|---|
| 项目一 · 接金币游戏 | 一句话做成 → 跑 → 改 → 上传 | 用一句话让 AI 做出小游戏，跑起来，改到能玩，上传平台 | 第一课·游戏 |
| 项目二 · 心情电量 | 记录心情 → 存起来 → 画出电量曲线+小结 | 做一个记录心情、存数据、画曲线的工具 | 第二课·工具 |
| 项目三 · 内心戏 | 搭骨架（人设+界面+接AI）→ 让它读懂你 | 创造一个懂你的 AI，先搭骨架，再教它观察、复述、把话说出口 | 综合课·AI应用 |

> 预备课内容（教"把话说清楚"）已并入各项目，作为开场集中讲，不单列。

## 二、六大类卡点 → 判断信号 → 对应知识点

> 判断 skill 读对话后，按此表归类：学生表现出哪个卡点，就归到对应知识点。

### ① 沟通指挥类 · 卡点：话说不清

| 知识点 | 判断信号（学生对话中出现了…） |
|---|---|
| 照着做（给参照） | 只说"做个游戏"，没说参照物；或来回"不是这样"却不说清要怎样 |
| 先做最小的（定范围） | 一上来要全部功能，不先做最小版本；描述范围过大 |
| 做之前先问我（要确认） | 不确认就放手让 AI 做，结果跑偏才回头 |
| 一次一小步（分步走） | 一次要求做一大坨；被 AI 反问"先做哪一步"时答不上 |
| 说不清时列表格 | 表达混乱、漏信息；AI 追问时才一点点挤出来 |
| 让 AI 帮你说清楚 | 卡在"不知道怎么说"，没让 AI 反问他/帮他整理 |
| 复述确认 | 不确认 AI 的理解就直接开工 |
| 贴图 | 该给截图/示例的地方，只用文字描述 |

### ② 项目推进类 · 卡点：不知道下一步

| 知识点 | 判断信号 |
|---|---|
| 模糊想法→多想方案再选 | 只有一个想法就开做，不先比方案 |
| 拆出第一步 | 卡在"不知道从哪开始"，没让 AI 拆第一步 |
| 中途问进度 | 做到一半闷头继续，不问"现在到哪了" |
| 卡住先暂停 | 卡住死磕不动，不暂停不求助 |

### ③ 工具操作类 · 卡点：手不会用

| 知识点 | 判断信号 |
|---|---|
| 打开/运行/预览 | 页面打不开、运行不了、不知道在哪预览 |
| 装/用 Skill | 不会装 Skill、装了不会用 |
| 建/用知识库 | 不会建知识库、知识库用不起来 |
| 用 Agent | 不知道 Agent 是什么、不会让 AI 干活 |
| 跑起来+分享 | 做完了不会跑、不会发布/分享 |

### ④ 容错纠错类 · 卡点：一做就错、报错看不懂

| 知识点 | 判断信号 |
|---|---|
| 先规划再动手 | 没想好就开做，反复推倒重来 |
| AI 会错很正常 | 一看到 AI 出错就慌、以为是自己全错 |
| 先做 demo 验收 | 不先跑小 demo 确认对错 |
| 把错说清楚 | 只喊"不对""报错了"，没说清视觉错/逻辑错/报错信息 |
| 让它改 | 不主动让 AI 改，自己硬扛 |
| 改完再跑 | 改了不重跑验证 |
| 重开 | 死磕到崩溃，不知道重开一个 |

### ⑤ 安全保障类 · 卡点：怕改坏、怕丢、回不去

| 知识点 | 判断信号 |
|---|---|
| 先存一份（保存） | 做了一大半没保存/没备份 |
| 回退/撤回 | 改坏了不知道能撤回 |
| 知道操作在哪 | 不知道这些按钮在界面哪里 |
| 看不懂的文件别删 | 乱删看不懂的文件导致出问题 |

### ⑥ 记忆续接类 · 卡点：记不住、接不上

| 知识点 | 判断信号 |
|---|---|
| 装记忆插件 | 反复说同一件事，AI 每次都像没听过 |
| AI 会记住 | 不知道 AI 能记住，重复交代 |
| 续接进度 | 第二次开会话不会续接，从头再来 |
| 控制上下文 | 对话堆太长不处理，越聊越卡/越忘 |

## 三、判断输出格式（给老师的诊断）

> skill 判断后，输出一份简洁诊断，老师瞟一眼就懂。分两层。

**个人诊断**（选中某学生时）：
```
学生 X · 项目二 · 环节「记录心情」
卡点：① 沟通指挥类 · 说不清时列表格
证据：「我做了个东西，但是不对。你帮我改改。」（未说明哪里不对）
建议：让他说清「哪个字段填错了、期望是什么」
```

**全班诊断**（某一环节后）：
```
环节「一句话做成游戏」· 全班 8 人
共性问题：3/8 人「只说要做什么，没给参照」，1 人「一上来要全部功能」
建议：下个环节开场花 3 分钟补「先做最小的」示范
```

---

## 四、红线

1. 判断要**引用学生原话**作证据，不凭空下结论。
2. 不贴"笨/不会/差"标签，只描述卡点 + 给建议动作。
3. 数据不足时不硬判断（对话太少标"样本不足"）。
4. 判断结果只给老师看，不上大屏、不展示给学生。
