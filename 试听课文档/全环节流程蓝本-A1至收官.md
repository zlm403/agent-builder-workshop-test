# 一、A1 · 数字分身（让 AI 用你的声音说话）· 21 屏

## 我们在做什么
把"你自己"蒸馏出来交给 AI——AI 先通过采访认识你、形成"分身档案"，再让分身替你写一条朋友圈，反复校准到"这确实像我说的"。**A0 说 AI 是伙伴，A1 兑现"伙伴"**：AI 用你的声音说话的那一刻，它就不是工具了。

## 教师端页面序列（20 页，逐页点击推进）
`钩子开场 → c1发现问题 → c2发布任务 → c3选择真实任务 → c4AI采访 → c5补充真实样本 → c6生成分身档案 → c7校准档案 → c8第一次写朋友圈 → c9判断像不像 → c10调整 → c11最终验收 → c12保存分身 → c13梦想 → c14一个到一群 → c15分析 → c16现实与紧迫 → c17结论 → 作品墙 → 认知对比图 → 视频`

> 大屏顶部全程钉住目标横幅：**🎯 目标：创造一个小小的数字分身，让它替我写一条朋友圈文案——看它做不做得到、写得像不像我。** 上方有 17 格进度条（1-12 任务链紫 / 13-17 升华链黄）。

# 二、A2 · 快速入门网站（帮一个小白进入陌生领域）· 16 屏

## 我们在做什么
每个人选一个**自己感兴趣但不懂**的领域，和 AI 一起做一个**手机网站**，帮一个完全不了解的人快速看懂门道、做出第一次判断和行动。**核心体验：我不需要先学完这个领域，也能帮别人进入它。**

> 对应「我马上就能搞」六座山：目标→知识→内容→技术→质量→迁移。总时长约 15 分钟。

## 教师端页面序列（14 页）
`钩子开场 → s1发布任务 → s2明确目标 → s3获取领域地图 → s4判断与收缩 → s5生成可用内容 → s6生成网页 → s7第一轮自检 → s8同伴测试 → s9根据反馈修改 → s10能力迁移 → s11提交与成果 → s12升华 → 作品墙`

> 大屏顶部全程钉住目标横幅：**🎯 目标：做一个「快速入门网站」，帮一个完全不懂的人看懂门道、作出第一次选择。** 上方有 12 格进度条。

# 四、收官（两部分：一人公司 + 报名转化）

## 4.1 finale · 一人公司（AI 组建队伍）· 3 插槽 + 学生端 8 步

### 我们在做什么
把"一个人 + AI = 一支军队"落到动手体验：学生开一家**一人公司**（AI 学习中心 / AI 好物店 / AI 娱乐社），招 3 名 AI 专家，发现重复工作，招统一前台接待，让 AI 总经理整顿，最后开门营业服务一位客户、真收一笔钱。

### 大屏 4 屏讲解态（SCREEN_SLIDES，教师可翻页）
| 屏 | 大屏显示 | 我们讲什么 |
|---|---|---|
| 第一屏 · 个体户 | "你已经有了一名全能员工"——一个人干完整个流程（接待→诊断→服务→检查），不需要休息、独立接单交付 | 呼应前面做的分身/员工 |
| 第二屏 · 复制扩张 | "把成功模式复制成一支团队"——英语老师能这么干，物理、化学、数码、穿搭……复制出去，每人管一摊 | 一人变成一支专业团队 |
| 第三屏 · 暴露重复 | "可是，每个人都在重复接待"——8 个老师都自己接待、自己分诊，重复劳动把专业时间全吞了 | 公司长大后的第一个病 |
| 第四屏 · 统一入口=公司 | "抽一个前台，公司才真正成型"——统一接待员听懂需求再自动分流给对的专家。多个专业员工+一个前台=一家会协作的公司。今天你们每个人都会亲手搭一家这样的公司，再让它真接一单、真收一笔钱 | 点题 + 下达任务 |
