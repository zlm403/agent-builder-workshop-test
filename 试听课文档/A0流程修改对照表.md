> 核心原则：把原来"并排放置"的好东西，串成一条心理路径：**看世界 → 看自己 → 看关系 → 看做事 → 看未来 → 回到现实 → 进入三个案例**。

## 一格一格对照表（现流程 → 新流程）

| 现在的流程 | 修改后的流程 | 为什么这样改 |
|---|---|---|
| 1. 手指图：接触AI的瞬间，重点标记"开头" | **1. 手指图 → 你第一次接触AI的故事**。不要急着讲AI，先让学生进入"我和AI第一次相遇"的个人记忆 | 开头不用改方向。作用是让AI从"科技话题"变成"我生命中已经发生过的一件事"。心理上是**代入**，不是学习 |
| 2. 讲你的故事 + AI里程碑表（ChatGPT 3.5以来，中外，二维图） | **2. 你的故事 → 二维AI发展图**。二维图保留，但重点不是"模型发展史"，而是：横轴=时间，纵轴=**人们开始用AI做什么**。让学生看到"AI能力和人的使用方式不断向上" | 二维图承担第一段**情绪上扬**。不要讲成技术史，让纵轴成为"人能借AI做什么"，才能和后面的人-AI关系接上 |
| 3. 1分钟快问：学生手机回答三问 + 推大屏 | **3. 三问，但此时先不公布"工具/伙伴"**。告诉学生："不用想太多，就说说你平时到底怎么用AI。"系统收集真实使用行为 | **不要提前告诉学生这是关系测试**，否则学生会为了得到"伙伴"而刻意回答。现在更像自然聊天，数据更真实 |
| 4. 大屏显示：不显示学生填的；显示里程碑时间线，别人哪年干过什么贴出来，让学生对照位置 | **4. 二维图再次成为"镜子" → "我们在哪儿？"**。这里不再继续讲，而是让学生自己把自己放进这张图。明确停一下，让"我们在哪儿？"成为心理停顿 | **最想保留、甚至强化的地方**。前面一直向上，这里第一次出现**下降**。不是告诉学生"你落后了"，而是让他自己发现："AI已经走到这里了，我好像还在这里。"叫**认知落差**，不是制造焦虑 |
| 5. 关系判定：三问在这里出现，系统判定工具/伙伴，大屏显示两边占比 | **5. 揭晓刚才三问的结果：工具 X% / 伙伴 X%**。告诉学生："刚才我们其实不是在测试你懂不懂AI，而是在看一件事情——我们平时到底把AI当成什么。" | 做成一个**揭晓时刻**。学生刚才并不知道自己在被判断，现在突然看到全班结果，产生第二次落差：**"原来我们班大多数人和AI还是这种关系。"** |
| 6. 工具 vs 伙伴分析：什么是工具/伙伴？为什么他觉得是工具？分析过去、现在、未来，放工具图+伙伴图 | **6. 先不要直接讲定义。先问："为什么会出现工具和伙伴的区别？"**然后进入**六步做事流程 + 人/AI滑块**：让学生看到，在一件真实事情的不同环节，人和AI的优势其实不同。之后再总结"工具"和"伙伴" | 原来**最容易讲成"老师讲概念"**的地方。六步滑块能把抽象的"工具/伙伴"变成具体问题：**一件事情到底谁更适合做哪一步？**学生不是听懂定义，而是自己发现"关系为什么会改变" |
| 6后半：过去/现在/未来的做事方式 | **6后半：六步滑块 → 过去/现在/未来**。过去：没有AI，人+工具；现在：部分环节开始有AI；未来：越来越多环节由人和AI共同完成 | "过去/现在/未来"不再只是预测未来，而是在解释：**为什么我们今天会出现"工具"和"伙伴"两种关系**。是前面体验的解释，不是另外一段知识 |
| 6后半：工具图+伙伴图 | **7. 两张图最后出现，不解释，先让学生选择："你更愿意成为哪一种？"**左图：人驾驭工具；右图：一个人拥有一群强大的AI。然后再问"为什么？" | 两张图**后置**。最适合做"未来想象"。右图不是简单的"AI伙伴"，而是：**一个普通人获得了一支远超个人能力的AI力量**。比讲"伙伴"两个字有冲击力得多 |
| 7. 电子海啸图 + 三个视频（罗振宇/腾讯/央视）+ A1过渡 | **8. 收束：不叫"电子海啸"，而是："这个东西已经来了。"**然后问："我们能感觉到吗？能看到它吗？"再用视频作为现实世界的证据。最后自然进入后面的三个案例 | **"海啸"太吓人**。要的不是恐惧，而是"突然发现它已经在身边"。视频不是重复"AI很厉害"，而是证明：**刚才讨论的东西，不是未来幻想，而是现实已经发生的变化** |

## 三个最核心的修改

**第一，把二维图当成"镜子"，而不是"教材"。**
不是为了让学生学会AI发展史，而是让学生最后看到一句：**我们在哪儿？** 这句话就是第一个心理转折点。

**第二，把六步滑块从"工具/伙伴解释器"，变成"工具/伙伴发现器"。**
不要先告诉学生"工具是什么，伙伴是什么"，而是让他先玩："一件事情的每一步，到底谁更适合？"然后学生自己发现："原来人和AI的关系不是一句'工具'或者'伙伴'就能说清楚的。"

**第三，两张图不是用来解释，而是用来"点燃想象"。**
尤其右边那张——一个人坐在巨大AI机器人的脑子里，外面还有一群AI面对整个世界。它最后回答的不是"什么是AI伙伴"，而是：**"如果一个普通人真的拥有这样的AI力量，他还能做什么？"** 这就开始为后面的三个案例铺路了。

---

## 第一部分最终心理曲线

> **AI离我越来越远 → 我突然发现自己没有跟上 → 原来我的使用方式只是工具 → 原来人和AI可以重新分工 → 原来我可以拥有一支AI力量 → 而这一切已经开始发生。**

然后，三个案例才真正有了出场的理由。
