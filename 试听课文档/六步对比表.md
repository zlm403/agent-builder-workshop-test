# 六步流程 · 新旧定义对比

| 阶段 | 旧版：目标创造型 | 新版：问题解决型 |
|---|---|---|
| 目标定义 | 明确"我要什么"：解决什么问题、创造什么、对象是谁、成功标准是什么、为什么值得做。 | 发现问题 / 明确目标：识别"哪里出了问题、我要达成什么"。 |
| 方案设计 | 把模糊想法拆成可执行路径：需要哪些步骤、什么资源、先后顺序、有哪些限制。 | 收集信息：搜集背景资料、相关数据、约束条件，把问题看得更全。 |
| 能力调动 | 决定哪些交给 AI、哪些自己完成：组合 AI、工具、知识库、角色、人脉。 | 分析判断：对信息做分析，判断关键点在哪、哪个方向可行。 |
| 执行创造 | 实际制作、生成、发布、交付，让方案变成真实作品。 | 设计方案：基于分析设计实现路径与步骤。 |
| 结果验证 | 检查效果、用户反馈、数据分析、自我判断，评价结果是否符合目标。 | 执行创造：实际执行、制作、生成。 |
| 迭代优化 | 发现问题、调整目标、修改方案、优化流程，让下一次更好。 | 验证迭代：检验结果并反复调整。 |
