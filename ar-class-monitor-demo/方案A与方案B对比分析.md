# 方案A vs 方案B · 对比分析

> 「AR 教学监控系统」学生端两种实现路线的详细对比
> 生成日期：2026-08-07

---

## 一、本质区别（一句话）

- **方案A（顷悟 AI 应用版）**：你的学生端页面**借用顷悟平台**这个现成的 AI 服务商——学生登录、AI 回复、计费全由平台负责，你只写前端页面。
- **方案B（自写前端版）**：你的学生端是**完全属于你自己的网页**——学生直接进、AI 回复由你自己的服务器提供，登录、计费、监控、界面全部自己掌控。

> 两张学生端的页面长得几乎一样，因为**外观是我故意做成一样的**，方便你只看架构差异，不被界面干扰。区别全在"页面背后谁来干活"。

---

## 二、核心对比大表

| 维度 | 方案A · 顷悟 AI 应用版 | 方案B · 自写前端版 |
|---|---|---|
| **学生登录** | 需要顷悟账户，首次进页面弹平台授权登录窗 | 免登录，填学号直接进 |
| **学生看到的登录痕迹** | 页面有「登录」按钮、平台授权弹窗 | 完全没有，纯白标（品牌完全属于你） |
| **AI 回复从哪来** | 顷悟平台 SDK 直连，平台大模型 | 你自己的后端/网关（demo 里是内置模拟回复） |
| **AI 成本谁付** | 扣**学生**的顷悟账户余额（或你充值） | 看你自己的 AI 后端成本，完全由你控制 |
| **API Key** | 不需要，平台 pccc 自动注入（安全） | 前端绝不塞 key，key 只存在你自己服务器 |
| **监控数据怎么拿** | 在 `ai.chat()` 外包一层埋点，截获请求/回复 | 所有操作、输入、回复天然经过你的代码，想记什么记什么 |
| **监控隐蔽性** | 学生能看到顷悟登录窗 → 知道在用第三方平台 | 完全无感，学生以为只是普通的课堂网页 |
| **开发工作量** | 小：登录/计费/合规/大模型平台全包 | 大：AI 接入、计费、账号体系、合规都要自己搭 |
| **技术依赖** | 强依赖顷悟平台 SDK 和平台环境 | 只依赖你自己的服务器，随时可换 AI 供应商 |
| **部署方式** | 上架顷悟平台，平台托管 | 自己托管页面（任意服务器 / 局域网） |
| **能否上商店** | 可上顷悟商店，自带计费和详情页 | 上不了平台商店，只能自己发链接 |
| **数据归属** | 学生数据 + 对话会经过顷悟网关 | 全部数据只经过你自己的服务器 |
| **合规要求** | 平台已有合规框架，但学生能感知第三方 | 完全白标，课堂监控需提前告知学生（合规自己负责） |
| **最适合的场景** | 快速上线、想省后端开发、接受平台登录 | 教学场景要完全自控、白标、隐蔽监控 |

## 三、通俗类比（换个角度理解）

### 方案A = 在美团外卖平台上开店
- 平台给你店铺页面、接单工具、收款体系——你省事，马上能开张；
- 但**顾客（学生）必须下载美团、在平台下单**（登录顷悟）；
- 平台知道你的每一笔交易（对话数据过顷悟网关）；
- 平台还抽成（按学生账户余额扣费）。

### 方案B = 自己开一家街边小店
- 店面、招牌、收银、进货全是你自己的；
- 顾客推门就进，不用注册任何平台账号；
- 店里发生的一切，只有你自己知道；
- 但**一切都是你自己干**——AI 厨师（后端）要自己请，账要自己记。

---

## 四、对你的影响 vs 对学生的感知

| 关注点 | 方案A | 方案B |
|---|---|---|
| **对老师** | 开发省事，但数据、成本、品牌都"借"平台的 | 开发多一点，但一切可控、数据全在自己手里 |
| **对学生** | 会看到"顷悟"登录窗，知道自己在用某个 AI 平台 | 无任何感知，打开就是课堂工具的样子 |
| **对监控效果** | 埋点能拿到，但要包一层 SDK 调用，个别平台内部环节看不到 | 全部环节都能记录，包括页面停留、步骤卡点 |

---

## 五、决策建议（什么时候选哪个）

**选方案A，如果你：**
- 想最快把系统跑起来，不想自己写 AI 后端
- 学生本身有顷悟账号（或愿意注册），接受平台登录
- 打算上架顷悟商店，靠平台分发和计费

**选方案B，如果你：**
- 这是**课堂教学现场**，希望学生无感知、品牌统一（强烈推荐这个场景）
- 要监控的数据越全越好，包括平台管不到的细节
- 自己已有/愿意搭 AI 后端，不想被单一平台绑定

**我的推荐（结合本项目实际场景）**：
> 这是**课堂内**用的教学监控工具，学生端体验和隐蔽性是第一位的 → **方案B 更合适**。
> 而且两个方案的埋点代码几乎一样，真到想省后端的那天，从 B 切到 A 成本很低，不冲突。

## 六、动手验证建议

两个方案我都打开了，你可以分别操作一遍，重点看**右上角**：

1. `http://localhost:8099/plan-a/` → 右上角有「未登录 · 点击登录」按钮（这是顷悟铁律，登录入口必须存在）
