## 三、数据链路（两路数据，一个事件流）

```
学员与顷悟对话  ─┐
                 ├─→ agent-live/events.jsonl ─→ 三端读取
学员作品互动    ─┘   (lib/track.js POST /api/collect)
```

- **对话数据**：顷悟 Agent 对话经 `agent-conversation-log` 技能自动写入事件流（每轮自动，静默无弹窗）
- **作品互动数据**：作品页面预埋 `lib/track.js`，学员一互动（提交想法/闯关/生成方案/拆解任务…）即上报
- **老师任务推送**：老师端写任务槽，学生端轮询秒读（`task_push` / `task_view`）

事件统一格式：`{ ts, sid, event, payload }`，六色状态：✅已确认 / 📋已识别 / 🟡推测 / △待澄清 / ⬜空缺 / 🔴冲突

## 五、讨论时可能要讲的三个点

1. **老师端能看到什么**：每个学员的对话（🤖）+ 作品操作轨迹（🖥）+ 六色缺口分析 → 决定下一轮推什么任务
2. **学生端"镜子"**：学生能看"我以为做到了 vs 实际缺了什么"，是教学反馈闭环的核心
3. **大屏**：匿名化投影（无姓名、无学号），只展示班级整体棱镜填充情况，适合观摩不泄露隐私
