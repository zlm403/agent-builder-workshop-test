> 汇报口径：这堂课教什么 / 怎么教 / 时间怎么排 / 上什么内容 / 怎么互动 / 配套流程 Demo

## 0. 一句话

**一天 4 课，教学生"用 AI 做事的底层能力"——从说清楚想法，到有依据地回答问题，到按流程做出一个服务，到搭出一套 AI 员工能力系统；全程后台无感收集数据，老师随时看见全班每个人的理解到哪了、哪里没立住。**

---

## 1. 这个课在教什么？（对象与目标）

**对象**：大学生 · AI 实践整日课程
**目标**：不是教某个工具怎么用，而是立起一套**"理解棱镜"**——用 AI 做事时脑子里必须立住的四组维度：

| 维度组 | 通俗说法 | 能力升级线 |
|---|---|---|
| ① 对象与目标 | 你想让 AI 帮谁、干什么 | 模糊想法 → 清晰表达 |
| ② 资料与边界 | AI 凭什么回答、能答到什么范围 | 会回答 → 有依据地回答 |
| ③ 流程与规则 | 一个服务怎么一步步做出来、守什么规矩 | 回答问题 → 完成服务 |
| ④ 能力与工具 | 复杂任务怎么拆给人/工具协作 | 单个员工 → 能力系统 |

**四课各承接一组，一天下来维度层层叠加，形成完整的理解棱镜。**

---

## 2. 怎么教？（方法）

**任务驱动，做中学，无感捕获，棱镜显影，闭环反馈。**

1. **不做抽象讲解**——每课就是一个真实可用的作品任务（表达、游戏、工具、AI 应用）
2. **学生在顷悟里真做**——跟 AI 对话、操作自己的作品，边做边学
3. **数据无感收集**——对话每一轮、作品每个关键操作，后台自动收进事件流，老师不用催交
4. **理解棱镜显影**——系统把学生的操作轨迹"显影"成六色维度图（✅已确认 / 📋已识别 / 🟡推测 / △待澄清 / ⬜空缺 / 🔴冲突），学生照镜子、老师看全班
5. **闭环反馈**：学生做 → 系统捕获 → 穿透成维度 → 三端反馈 → 老师看聚合 → 老师推下一步 → 学生再做

## 3. 时间上怎么安排？

**一天整日课，四课按维度递进**（预备 → 第一 → 第二 → 下午综合）。具体钟点可随班级节奏调整，结构固定：

| 阶段 | 课 | 时长特征 | 核心任务 |
|---|---|---|---|
| 上午·轻量开胃 | 预备课 | 轻量 | 说出"我想做个什么"（表达梳理） |
| 上午·游戏化 | 第一课 | 中等 | 做"答疑闯关"游戏（资料边界） |
| 上午·工具化 | 第二课 | 中等 | 做"活动方案生成器"（流程规则） |
| 下午·综合 | 综合课 | 较重 | 做"多员工 AI 应用"（能力系统） |

- 每课收口有**固定验收**：用一句话说清「给谁 / 什么场景 / 帮什么 / 怎样算成功」
- 老师可随时「推步骤」让全班同步进入下一环节，节奏由老师掌控

## 4. 上什么内容？（四课明细）

| 课 | 学生做什么 | 教学点 | 立什么棱镜 |
|---|---|---|---|
| **预备课 · 表达梳理台** | 输入一个模糊想法（如"我想做个帮大家背单词的东西"）→ AI 帮你梳理成四字段（对象/目标/怎么做/难点）→ 确认修正 → 得到清晰表达 | 从模糊想法到清晰表达 = 说清**对象和目标** | 语言棱镜（10 格：对象/场景/问题/任务/目标/标准/范围/互动/限制/输出） |
| **第一课 · 答疑闯关游戏** | 把课程资料喂给 AI → 游戏化闯关问答 → 每题展示"依据" → 故意问资料外的问题，看 AI 会不会拒绝瞎编 | 有依据地回答 = 资料内给答案+依据，资料外不编造 | 边界棱镜（5 格：资料整理/有依据回答/边界测试/测试深度/边界外处理） |
| **第二课 · 校园活动方案生成器** | 填活动需求 → 工具收集输入→检查→拆步骤→设规则→规范输出→测异常（如人数超容量给提示、违规输入被拦截） | 从回答问题到完成服务 = 一套**流程与规则** | 规则棱镜（6 格：输入收集/信息检查/步骤拆解/规则约束/规范输出/异常测试） |
| **综合课 · 多员工应用工坊** | 输入目标（如"办一场校园迎新晚会"）→ AI 拆能力 → 自动配员工 → 员工选工具 → 设计交接链 → 测试对话 → 发布团队说明书 | 复杂任务 = 目标拆能力 → 分员工 → 选工具 → 设计交接 → 测试发布（**能力系统**） | 系统棱镜（5 格：目标拆解/员工分工/工具选型/交接设计/测试发布） |

> 关键设计：每课的"形态"（输入框/游戏/工具/应用）只是载体，**对话与操作始终被捕获**——做任务的过程本身就是被评估的数据。

## 5. 怎么去互动？

**六类互动，全部在一个闭环里：**

| 谁 ↔ 谁 | 怎么互动 | 系统角色 |
|---|---|---|
| 学生 ↔ AI | 在顷悟里对话（每轮请求/回复被记录） | 对话捕获 |
| 学生 ↔ 作品 | 操作自己的游戏/工具/应用（关键动作被埋点） | 作品埋点 |
| 老师 → 学生 | 推步骤（全班同步 / 定向到个人）→ 学生看板收到、大屏同步亮灯 | 任务推送 |
| 学生 ↔ 自己 | "我的理解棱镜"：看到「我以为说的 vs AI 实际听到」的差距，自己决定补哪格（镜子不说教、不自动改） | 棱镜显影 |
| 老师 ↔ 全班 | 聚合看板：全班哪格最弱、谁卡住了、清晰度分数环 → 决定下一步推什么 | 聚合分析 |
| 班级 ↔ 大屏 | 匿名投影：无姓名学号，只看"全班 8 人对象🟡、5 人场景⬜"→ 带全班一起补短板 | 匿名隐形壳 |

**闭环一句话**：学生做 → 系统无感捕获 → 穿透成维度 → 三端各看各的 → 老师看聚合 → 老师推一步 → 学生再做。四课层层叠维度，一天下来全班的理解棱镜从大片空白被填满。
