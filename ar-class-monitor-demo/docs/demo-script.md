## 1. 演示流程（建议 15-20 分钟）

### 第 1 幕：学生端（2 分钟）
1. 打开 `student/`，展示 4 课切换（预备/第一/第二/综合）
2. 每个课有：任务看板 + 本课引导 + 作品运行容器
3. 点开某课，作品在 iframe 里直接跑

### 第 2 幕：预备课 · 表达梳理台（3 分钟）
1. 打开 `warmup/`，输入一个模糊想法（如"我想做个帮大家背单词的东西"）
2. 点「AI 帮我梳理」→ 展示四字段梳理（对象/目标/怎么做/难点）
3. 点「去确认」→ 修改其中一项 → 润色 → 复制最终表达
4. **教学点话术**：让学生理解"从模糊想法到清晰表达"= 说清对象和目标

### 第 3 幕：第一课 · 答疑闯关（3 分钟）
1. 打开 `game/`，开始闯关答题（每题答完展示「依据」）
2. 切到「边界测试」，输入资料外问题（如"明天天气"）→ AI 拒绝回答
3. **教学点话术**：有依据地回答 = 资料内给答案+依据，资料外不瞎编

### 第 4 幕：第二课 · 活动方案生成器（3 分钟）
1. 打开 `tool/`，填活动信息（人数 300 > 教室容量 80 → 提示换场地）
2. 正常生成方案（六环节：筹备/流程/物资/分工/预算/应急）
3. 切「异常测试」故意给违规输入 → 工具拦截
4. **教学点话术**：从回答问题到完成服务 = 收集输入→检查→拆步骤→设规则→规范输出→测异常

### 第 5 幕：综合课 · 多员工应用工坊（4 分钟）
1. 打开 `agent-team/`，输入目标"办一场校园迎新晚会"
2. 展示 AI 拆能力 → 自动配员工 → 员工选工具
3. 设计交接链（可调顺序）→ 点一个员工对话测试
4. 生成团队说明书 → 复制
5. **教学点话术**：从单员工到能力系统 = 目标拆能力 → 分员工 → 选工具 → 设计交接 → 测试发布

### 第 6 幕：学生端 · 我的理解棱镜（3 分钟）
1. 打开 `student/`，右上角填学号 `demo_li`，切到预备课
2. 展示「我的理解棱镜」：demo_li 只有"要完成的任务"亮，其余 9 格全空，回读句显示"我理解你想让 AI 帮你做「帮我弄个东西」……所以你大概率会先做一个泛泛的、不贴任何人的东西"
3. 换学号 `demo_zhang`：8 格绿、回读句"使用对象=大学、使用场景=每天、当前问题=记不住……"，只剩内容范围/限制条件两个缺口
4. **教学点话术**：镜子不说教、不自动改——只让学生亲眼看到"我以为说清了 / AI 实际听到"的差距，自己决定补哪格

### 第 7 幕：老师看板 · 班级理解棱镜（4 分钟）
1. 打开 `monitor/`，展示：
   - 学生列表（demo_zhang / demo_li / demo_wang + 老大的顷悟 Agent 对话记录）→ **每人有清晰度分数环 + 缺口数**
   - 时间线（按来源筛选：🖥 作品 / 🤖 Agent / 📨 任务）
   - **班级理解棱镜**：按课切换（预备/第一/第二/综合），每课显示各自的维度表——预备课语言棱镜 10 格、第一课边界棱镜 5 格、第二课规则棱镜 6 格、综合课系统棱镜 5 格；每格显示全班「最常见状态」，**橙色描边 = 全班普遍没立住的维度**（课堂要一起补的）
   - 选中学生 → 穿透分析：对话轨迹 + 作品使用轨迹
2. **教学点话术**：两路数据 = 生产过程数据（对话）+ 产品数据（作品使用）；棱镜不是一套格子套到底，而是**每课穿它该穿的东西**——预备课看想法说清没、第一课看依据在不在资料里、第二课看流程规则立没立、综合课看能力系统成没成。老师一眼看到全班哪个维度弱，就能决定下一步推什么。

### 第 8 幕：大屏匿名投影（2 分钟）
1. 打开 `bigscreen/`（投教室大屏），展示：
   - 左栏：今日课程进度（四课是否已有学生操作）
   - 中栏：班级理解棱镜填充——每 8 秒自动轮播四课，每格颜色 = 全班该维度最常见状态，**橙色描边 = 全班普遍没立住的维度**（课堂要一起补的）
   - 右栏：匿名学生墙——只显示首字符 + 清晰度分数环 + 缺口数，**不显示学号姓名**
2. **教学点话术**：大屏是"匿名隐形壳"——不点名、不羞辱，让全班看到"我们班整体到哪了、哪里还没立住"，老师带全班一起补短板。
